# The Two Guards

A pixel-art riddle game in three levels.

1. **The Two Guards.** Two doors, two guards: one always tells the truth, one always lies. Ask one guard one question, then pick a door.
2. **Knights and Knaves.** Escape and you reach an island. Three islanders each make a statement; knights always tell the truth and knaves always lie. Mark who is who.
3. **Who is the Spy?** Solve the island and walk to the fortress. Four islanders, and exactly one is a spy who can say anything. Find the spy and mark everyone else.

The ending screen shows each level's result and time.

Play it: https://sukarnsingh-amici.github.io/two-guards/

- The whole game is one file, `index.html`. Open it in any browser to play offline (fonts need internet).
- Languages: English, Hindi and Hinglish, from the switch at the top. Sound can be turned off there too.
- Each device remembers its round, so a reload shows the same place and result. "New round" starts again from Level 1.
- Every Level 2 and 3 puzzle has exactly one answer, needs all its statements, and has no statement that gives anyone away. The game works out the answer from the statements, so no answer key is stored in the page.
- `og-image.png` is the picture shown when the link is shared on WhatsApp and other apps.

## Updating the live page

Edit `index.html`, commit and push to `main`. GitHub Pages republishes within a minute or two.
