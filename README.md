# The Two Guards

A one-round pixel-art riddle. Two doors, two guards: one always tells the truth, one always lies. Ask one guard one question, then pick a door.

Play it: https://sukarnsingh-amici.github.io/two-guards/

- The whole game is one file, `index.html`. Open it in any browser to play offline (fonts need internet).
- Languages: English, Hindi and Hinglish, from the switch at the top.
- Each device remembers its round, so a reload shows the same result. "New round" starts a fresh one.

## Updating the live page

Edit `index.html`, commit and push to `main`. GitHub Pages republishes within a minute or two.
